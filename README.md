# Hi, I'm Laith 👋

Frontend engineer working in **React, Next.js and TypeScript**. For 2.5 years at **MBC Shahid**, the largest
Arabic-language streaming platform, I co-built the video playback component library behind **8.7M monthly plays**
on web and Smart TV, and led an SEO revamp that more than doubled the site's indexed videos.

Based in Amman, Jordan. Open to remote roles and to relocating across the Gulf.

## 🎬 MBC Shahid (2024 – 2026)

- **SEO revamp:** server-side rendering, dynamic metadata, canonical URLs, sitemaps, Core Web Vitals and Schema.org
  structured data. Within four weeks, indexed videos rose 2.3× (69.7K → 161.7K) and video rich results went from 81 to 105K+.
- **Player abstraction:** co-designed one contract with pluggable Shaka Player, Bitmovin and RxPlayer implementations,
  so the platform can swap or A/B-test player SDKs without touching product code.
- **Playback component library:** co-built the React/Next.js library for web and Smart TV as a pnpm monorepo with
  90% unit test coverage, a Vite playground and architecture docs.
- **Product work:** shipped five features with zero post-release hotfixes, including content locking, credit-card
  offer validation and category browsing.
